# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct for participants across the repository, issue tracker, pull requests, and any community forums (Discord, mailing lists, etc.) that may be established later.

The full, canonical text lives at the Contributor Covenant website:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

Translations: <https://www.contributor-covenant.org/translations/>

## Enforcement

Concerns, questions, or reports of conduct that falls outside the Covenant's standards should be directed to:

- **Email:** `aakilabderr22@gmail.com`

Reports are handled in confidence. The maintainers will review every report, investigate as needed, and respond with the determined course of action. Reporters will be informed of the outcome.

## Scope

The Covenant applies within all project spaces, and also when an individual is representing the project or its community in public spaces. Examples of representing a project include using an official project email address, posting via an official social media account, or acting as an appointed representative at an online or offline event.
